# Clockwork-only prototype playtest

Use rules 0.1.0 without changing card values between sessions. Living Frontier is outside this implementation.

1. Play a teaching game in Pass & play or with the Automaton. Then let two people play a private room without coaching.
2. Reverse starting initiative using Rematch. Try at least two deals. Use the local seed input when reproducing a confusing position.
3. At the end, download **Game menu → Export save & replay** (local) or **Export public match log** (online), and **Playtest notes**. Notes stay local until the player chooses to share the downloaded file.
4. Record elapsed active play time, rounds, winner, unspent resources, skipped actions, rule questions, and whether both players choose another game. The journal includes all accepted gameplay and automatic transitions.

Ask: Which combination felt satisfying? Which rival move changed your plan? When did the winner feel decided? Which machine felt weak? What would you try in a rematch?

The initial human gate remains 4–6 pairs, observing completion without correcting game state and whether players voluntarily rematch. Automated simulations and browser checks validate operation, not strategic balance or the target duration.
