# Compare the two games fairly

Do not interpret polished art as evidence that a rule works. Build a playable local match of each with similar UI quality and stable rules versions.

## First pass

Recruit 4–6 pairs of willing players and run a small exploratory session set. Let each pair try both games, alternating which they play first. Use different draft seeds and reverse first-player advantage in rematches. These small samples reveal confusion and weak choices; they cannot estimate market success or win balance reliably.

Record: rules version/seed, game length excluding disconnection, winning seat/initiative, rounds, rule questions, unspent resources, obvious/pass turns, and whether they voluntarily choose another match. Do not silently add analytics during private tests; start with a simple local match export and feedback notes.

Ask after play:

1. Which combination felt satisfying, and why?
2. Which opponent action made you change your plan?
3. When did the winner feel decided?
4. What would you try differently next time?
5. Which game would you choose for another match now?

## Decision gates (working targets, not industry benchmarks)

- Most testers can finish without the designer correcting game state.
- Typical experienced matches land near 20–30 minutes; report the observed range rather than only an average.
- Players can name a meaningful opponent-driven decision.
- Several pairs voluntarily rematch and explore another approach.
- No obvious single strategy invalidates the rest of the initial catalogue.

If these fail, change the smallest relevant rule and replay the same scenario plus fresh seeds. Record balance changes in a changelog. Avoid changing three card values and phase structure simultaneously.

## Small online community

Launch private invite sessions before public queues. A new standalone game has no guaranteed opponent pool; schedule playtest windows and make rematches easy. Add optional practice only after the human loop works. A later returning-player measure should count distinct people who return on another day, not browser refreshes or total games alone. Public rankings, promotion and monetization follow evidence of repeat play.
